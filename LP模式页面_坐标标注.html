公式计算（动态值）

sdTop
= scroller.getBoundingClientRect().top
—
documentTop
= .cm-content 顶部在 scroller 中的 Y 坐标
—
= inlineTitle高度 − scrollTop（动态值！）
documentTop + scrollTop
= inlineTitle 高度 ≈ 624px
—
恒为常数 — 这就是为什么 documentTop 随 scrollTop 变化
scrollTop
= scroller.scrollTop（已滚出视野的内容）
—
inset
= documentTop − sdTop + scrollTop
—
坐标桥接值：连接 scroller 坐标系与 viewport 坐标系
screenTop
= lb.top − scrollTop + inset
—
文本行在视口中的像素位置
lb.top
= LineBlock 在 .cm-content 内的偏移量（0-based）
—
docRatio（正确公式）
= lb.top / scrollHeight
—
纯文档位置比，不含动态 documentTop
docRatio（错误公式 — 已废弃）
= (lb.top + documentTop) / scrollHeight
—
documentTop 随 scrollTop 波动 → 比值不稳定

LP 模式坐标系统图例

浏览器视口 — 可见区域的绝对参考系（顶+底粗实线标注）
sdTop — scroller 顶边到视口顶的距离
  ↳ = scroller.getBoundingClientRect().top
  ↳ 组成: 菜单栏(28px) + tab栏(38px) + 面包屑 + 间距
.cm-scroller (sd) — 可滚动容器（蓝色实线边框）
  ↳ sd.clientHeight — scroller 可见高度（因窗口而异）
  ↳ sd.scrollHeight — scroller 内容总高度（可滚动范围）
  ↳ sd.scrollTop — 已滚出 scroller 可见区域上方的像素数
documentTop — .cm-content 顶部在 scroller 中的 Y 坐标
  ↳ = inlineTitle高度 − scrollTop（动态值，随滚动变化！）
  ↳ documentTop + scrollTop ≈ 624px（常数 = inline title 高度）
inline title — Obsidian 根据文件名生成的标题（位于 documentTop 区域内）
  ↳ 第一个子元素，之后是 properties panel、然后是 .cm-content
inset — 坐标桥接值: documentTop − sdTop + scrollTop
.cm-content — 文档编辑区域（lb.top 参考系原点）
  ↳ lb.top — line block 在 .cm-content 内的偏移 (0-based)
折叠 YAML 源码 — 在 .cm-content 内部，非 documentTop
screenTop — 文本行在视口中的像素位置
= lb.top − scrollTop + inset
